# cnb-reels

Reels automáticos do CNB – Canal de News do Brasil (@canalnewsdobrasil).

- `AGENTE.md` – instruções das rodadas diárias (preparação 6h, agendamento 7h30).
- `ferramentas/` – molde do vídeo (`template.html`), gerador (`batch.js`) e trilha original (`trilha_cnb.mp3`).
- `pautas/` – pauta de cada dia.
- `videos/` – vídeos aguardando agendamento (apagados depois que o Metricool copia).
